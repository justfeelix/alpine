03 · the data

Where they are — and where the source is wrong

38 resorts have coordinates pointing somewhere else entirely. Found by cross-checking each stated base elevation against the elevation of its ERA5 weather cell — an error invisible to any check run against the source file alone. Their weather columns are set to NULL rather than quietly describing the wrong mountain.
